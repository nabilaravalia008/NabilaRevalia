## 🚀 Panduan Upload (Push) ke GitHub & Mengaktifkan GitHub Pages

Folder ini sudah **100% siap langsung di-upload ke GitHub**. Ikuti salah satu cara mudah di bawah ini:

### Cara 1: Lewat Browser di GitHub.com (Paling Praktis)
1. Buka [github.com](https://github.com/) dan buat repositori baru (misal diberi nama: `nabilapage-msip` atau `Sistem-Nabs-MSIP`).
2. Pada halaman repositori baru, klik tombol **"uploading an existing file"**.
3. Tarik (*drag & drop*) seluruh file yang ada di folder ini (`index.html`, `style.css`, `script.js`, `README.md`, dan semua foto `.jpg`) ke jendela browser GitHub.
4. Klik tombol hijau **"Commit changes"**.
5. **Mengaktifkan Website agar Live (GitHub Pages)**:
   - Masuk ke menu **Settings** di bagian atas repositori.
   - Pilih menu **Pages** di bilah kiri.
   - Pada bagian **Branch**, pilih `main` dan folder `/(root)`, lalu klik **Save**.
   - Tunggu sekitar 1 menit, website kamu akan langsung online dan bisa diakses dari mana saja! 🌐✨

### Cara 2: Lewat Git Terminal (Command Line)
```bash
git init
git add .
git commit -m "Upload lengkap portal nabilapage's MSIP FPIK ULM"
git branch -M main
git remote add origin https://github.com/USERNAME_KAMU/NAMA_REPO_KAMU.git
git push -u origin main
```
